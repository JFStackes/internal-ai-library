# Optional MCP integrations / Integraciones MCP opcionales

These are configuration templates, not Skills or agents. The installer never merges them, downloads packages, authenticates, or starts servers. All templates are disabled. Manually review and merge the desired table into a trusted project's `.codex/config.toml` (or personal `$CODEX_HOME/config.toml`), then explicitly enable it. Preserve existing configuration. Use `codex mcp list` and `/mcp` to inspect availability; authentication and real tool calls were **not tested** here.

- `openai-docs.toml`: official OpenAI documentation endpoint from [Codex MCP docs](https://developers.openai.com/codex/mcp). Remote, read-only documentation; no package installation.
- `microsoft365.toml`: [PnP server README](https://github.com/pnp/cli-microsoft365-mcp-server/blob/38ed9902e36378c3e0404366e44d57e1df3807b4/README.md), [package manifest](https://github.com/pnp/cli-microsoft365-mcp-server/blob/38ed9902e36378c3e0404366e44d57e1df3807b4/package.json), MIT, npm version **0.1.26**, Node **20+**. This pins the direct package, not its transitive dependency tree; enabling `npx` downloads and executes third-party code. Review the package/lock and provision tooling separately before enabling. It requires an installed `m365` CLI and uses its existing login. The template exposes documentation tools only, excluding `m365RunCommand`. The server can otherwise run arbitrary CLI commands and write tenant state. Do not grant tenant-wide consent as part of installing this library. Enable command execution only after a separate review of tenant scope, delegated permissions and action authorization. Tool filtering limits what Codex can call; it is not a sandbox for the server process.

No tokens, tenant IDs, certificates, app registrations or passwords belong in these templates. For a future authenticated HTTP server use `bearer_token_env_var`, not a literal token; for stdio forward only required `env_vars`. Keep local credentials outside Git. Never use an MCP setup flow as implicit authorization to write to production or send messages.

En español: son plantillas desactivadas que debes revisar e incorporar manualmente. La biblioteca no instala herramientas, inicia servidores ni autentica cuentas. El servidor PnP reutiliza la sesión de `m365`; la plantilla solo permite consultar documentación. No se ha probado acceso a ningún tenant. La configuración de permisos real depende de la cuenta y del proceso servidor; los agentes heredan los MCP de la sesión principal.
